<b>Goal: get help without leaving easyROB.</b><br><br>Select <b>robBOT</b> in the sidebar. You can ask about GUI controls, workflow stages, results, warnings, and AQME/ROBERT documentation while the workspace stays visible.

---

<b>Recognize the drawer.</b><br><br>robBOT opens beside the current page. The conversation and question box are at the top; <b>Answer settings and token usage</b> expands below them. Use the × button to close the drawer and the sidebar item to reopen it.

---

<b>Ask a specific question.</b><br><br>Type in the question box and press <b>Send</b> or Enter. For example, ask “What does VERIFY check in my workflow?” Mention the step or result you want explained. <b>Clear history</b> starts a new conversation.

---

<b>Use the built-in prompts.</b><br><br>Choose a question from the dropdown below the composer. It fills the question box; press Send to receive an answer. Questions about CheckML and robBOT are included.

---

<b>Summarize detected work.</b><br><br>After opening a project with outputs, use <b>Explain latest result</b> for a summary based on detected results. The button stays disabled when no suitable result is available.

---

<b>Choose the answer mode.</b><br><br>Expand <b>Answer settings and token usage</b> and use the <b>Mode</b> dropdown. Cloud AI uses a provider and API key. Heuristic gives rule-based help from local context.

---

<b>Configure Cloud AI if you want it.</b><br><br>Select a provider, enter its API key, and click <b>Save API</b>. The key field is masked and tied to that provider; switching providers clears the active key, and switching back restores the saved one. The optional web-search checkbox allows supported cloud providers to look up missing or current information.

---

<b>Use Heuristic for local guidance.</b><br><br>Select <b>Heuristic</b> for a rule-based answer using GUI state, popups, logs, and packaged knowledge. It needs no API key or AI model. Ask a focused question and inspect the answer beside the relevant GUI output.
