easyROB: the Graphical User Interface (GUI) of ROBERT
=====================================================

easyROB is the graphical user interface of ROBERT. It simplifies the setup of
ROBERT workflows, allowing users to select files, configure options, and inspect
results from a desktop application.

To run easyROB:

1. Install ROBERT as described in the "Installation" section of our Read the
Docs page:
https://robert.readthedocs.io/en/latest/Install/installation.html

2. Open an Anaconda prompt (Windows users) or a terminal (macOS and Linux).

3. Activate the conda environment where ROBERT is installed, for example:
`conda activate robert`

4. Launch the GUI with:
`easyrob`

If you are working from a local copy of the GUI instead of the installed
package, you can also run it from this folder with:
`python easyrob.py`

For more information, visit:
https://robert.readthedocs.io/en/latest/Install/gui.html
